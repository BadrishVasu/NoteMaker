# `.agents/` — the logbook

Where this project's progress is written down so it doesn't rest on anyone's memory.

- `JOURNAL.md` — session by session, newest first. Append; never rewrite a past entry.
- `features/<slug>.md` — one file per feature, its real current state. Edited in place.
- `notes/<agent>.md` — each agent's own notebook. Others read it; nobody else edits it.

The wayfinder map and its decision tickets live in `.scratch/notes-mvp/`. That's the
decision record; this is the progress record. **Link between them, never restate** — two
copies of the same fact drift, and the copy nobody trusts is worse than no copy.

Full protocol: `~/.claude/LOGBOOK.md`.
